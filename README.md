# 🎞️ LottieFiles Plugin for Bubble.io

**LottieFiles Plugin** is a custom plugin developed for [Bubble.io](https://bubble.io), allowing you to easily play Lottie animations within your Bubble applications. You can dynamically embed Lottie animations in JSON format.

## ⚙️ Features

- Supports Lottie JSON animations  
- Autoplay support  
- Loop control  
- Playback speed adjustment  
- Fully compatible with Bubble Workflows  
- Load JSON from external URL or dynamic data source

## 🔧 Technologies Used

- **JavaScript** – For animation playback using the Lottie Web library  
- **CSS** – For responsive animation container styling  
- **Bubble Plugin Editor** – Used to develop the custom plugin
